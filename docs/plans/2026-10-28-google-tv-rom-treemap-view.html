Area calculation and layout

All ROMs are squarified together by exact byte size; category colors identify each tile without constraining its shape. The details rail is outside the map. The SVG above is an illustrative layout—runtime rectangles are calculated from the loaded catalog sizes.

area(ROMᵢ) = map width × map height × sizeᵢ / Σ sizeⱼ

Exact area

Each tile’s width × height follows the ROM’s byte count. Category colors add meaning without changing geometry.

D-pad map

  • Arrows choose the nearest tile in that direction.
  • At map edges, up returns to filters and right enters details.
  • Select launches; Favorite and Play remain available in the rail.

Readable at scale

Names and sizes appear only when a tile has room. Every tile keeps an accessible title, filename, category, and byte count.

Performance: the map lays out once per result change and creates one button per ROM. It does not regenerate cards or reload ROM data. Selection changes only the focus outline and details rail.
