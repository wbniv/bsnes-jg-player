Design intent

Make the picker feel like a game menu, with a strong active-row state and all actions reachable with the TV remote. The small “featured” set is a fast start; the All Cartridges row opens the complete searchable catalog.

Interaction and tradeoff

  • D-pad moves the cursor; Select opens or loads; Back returns.
  • Search opens an on-screen keyboard with live title and filename completions; Backspace removes only typed letters.
  • Strongest option for Android TV and couch use.
  • Use pixel styling inside the player shell; avoid making technical source details hard to read.

Catalog-size behavior

How the game menu adapts

At runtime, derive list density and hierarchy from the loaded catalog count; these four sizes are checkpoints for one controller-driven UI.

1 ROM

Go straight to its title card and Play action. Put “Change ROM” in the pause or options menu.

10 ROMs

Show one flat D-pad list with the selected ROM preview and button prompts.

100 ROMs

Add category tabs and a compact list. Search opens a simple on-screen keyboard.

1,000 ROMs

Start with Recent, Categories, and Search. Browse one category at a time with a focusable, paged list; preserve letter jumps and selected-item focus.

What stays constant: a visible selection cursor, clear Select, Search, and Back prompts, and no deep menu paths.
