Design intent

Make the first screen usable from across the room. Recent and featured ROMs launch in one or two remote presses; Search and All ROMs provide direct access to the full published ROM library using only the TV remote and its on-screen keyboard.

Remote behavior

D-pad
Move focus among actions and cards; focused item grows and gets a bright outline.
Select
Launch the focused ROM or open its details.
Search
Open the on-screen keyboard; results filter as the query changes.
Completion
Suggested suffix is ghost text, never inserted into the query. Backspace deletes one typed letter; Select loads the focused result.
Back
Close search/details or return to the launcher.
Default focus
Featured Play action, then recent ROMs.

Why this is different

  • Search remains the fastest way to find an exact build, but is not the only first-screen path.
  • Large cards and persistent focus replace small text inputs and dense result rows.
  • Recent and pinned ROMs reduce repeated search on a TV.
  • The query and matching ROMs share the screen; Select launches the focused result.

Catalog-size behavior

How the Chromecast launcher adapts

At runtime, the launcher reads the loaded catalog count and adjusts browsing density. The 1 / 10 / 100 / 1,000 cases below are checkpoints, not separate screens.

1 ROM

Launch directly or show one focused Play tile and a small Change ROM action.

10 ROMs

Show the whole recent/all list as large focusable cards; Search can stay secondary.

100 ROMs

Use category shelves and Recent/Pinned rows, with Search always visible in the header.

1,000 ROMs

Keep the home screen sparse. Search opens the TV keyboard and a paged set of large results; category jumps and letter navigation reduce D-pad travel.

What stays constant: one focused item at a time, large targets, retained focus after Back, and Select launches the chosen ROM.
